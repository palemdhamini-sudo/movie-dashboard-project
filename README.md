# Movie Analytics Dashboard

## Overview

The Movie Analytics Dashboard is an interactive data visualization application that analyzes movie datasets and presents key insights through a clean and user-friendly dashboard. Built using **Python, Pandas, Streamlit, and Plotly**, the project enables users to explore movie trends, ratings, genres, revenues, and other performance metrics through dynamic charts and visualizations.

This project demonstrates practical skills in **data analysis, data visualization, dashboard development, and exploratory data analysis (EDA)**.

## Features

* Interactive dashboard built with **Streamlit**
* Data cleaning and preprocessing using **Pandas**
* Visual analysis of movie ratings, genres, revenue, and popularity
* Dynamic charts and graphs created with **Plotly**
* Filtering and exploration of movie data
* Summary statistics and insights for decision-making

## Technologies Used

* **Python**
* **Pandas**
* **NumPy**
* **Plotly**
* **Streamlit**

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/Movie-Analytics-Dashboard.git
cd Movie-Analytics-Dashboard
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application:

```bash
streamlit run app.py
```
